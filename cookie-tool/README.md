# 抖音 Cookie 获取工具

配套用于**在你的电脑上导出抖音 Cookie**，再粘贴到 Douyin Fire 面板的【个人中心】完成登录（适合不方便扫码的场景）。

> 实际程序压缩包：**`抖音Cookie获取工具-完整版(1).zip`**（见本仓库 **Releases** 页面下载）。
> 体积约 370MB，因为内置了 Playwright 浏览器运行时，**请勿单独抽取 exe**。

## 使用步骤
1. 将压缩包**整体解压**（保持 `抖音Cookie获取工具.exe` 与 `ms-playwright` 文件夹在同一目录，不要单独拿 exe 出来）。
2. 双击运行 `抖音Cookie获取工具.exe`。
3. 程序会打开内置浏览器，登录抖音后点击「**提取 Cookie**」。
4. 导出的 Cookie 可复制或保存使用。

## 功能
| 功能 | 作用 |
|---|---|
| 内置浏览器登录抖音 | 在工具内直接登录，与你的日常浏览器环境隔离。 |
| 一键提取 Cookie | 登录后一键抓取当前账号 Cookie，免去手动从开发者工具复制。 |
| Cookie 导出 | 支持复制或保存为文件，便于粘贴到面板。 |
| 内置 Playwright 运行时 | 自带浏览器，开箱即用（需 Windows 10/11 64 位）。 |

## 注意事项
1. `ms-playwright` 文件夹是程序内置浏览器运行时（约 700MB），必须与 exe 放在一起，删除或移动会导致程序无法启动。
2. 首次启动可能较慢（加载内置浏览器）。
3. 需要 Windows 10/11 64 位系统。
4. 抖音有风控机制，提取的 Cookie 可能被判定为异常环境，请以实际使用为准。
5. 本工具仅供**个人学习测试**使用，请勿用于非法用途。

## 常见问题
- **双击无反应**：请确认 `ms-playwright` 文件夹完整、未被杀毒软件隔离。
- **提示缺少浏览器**：请重新解压完整文件夹。
